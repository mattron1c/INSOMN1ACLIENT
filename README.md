# INSOMN1ACLIENT
A Minecraft Mod/Client with every Dawn and Lunar Client Feature


Is INSOMN1A safe? Yes, and you don’t have to take my word for it:
• It’s a normal Fabric mod. It never runs programs, and it only writes inside your Minecraft folder (its settings, and packs/shaders you choose to install).
• It connects to only 3 things: Mojang’s login check (the exact same one Minecraft uses when you join any server; your token only goes to Mojang), our server for friends/DMs, and Modrinth when you browse packs.
• It never touches your browser, Discord, passwords, or files outside Minecraft.
• The source code is public. Download it from Modrinth (when approved), or check the jar’s SHA-256.
• Don’t want the online features? Turn off INSOMN1A → Social and it never connects to anything.

Features: Every Feature of 🌙Lunar Client, excluding Hypixel settings
And every feature from 🌅Dawn Client: Excluding instant pvp matchmaking from MCPVP.
Custom Interactive UIS and every feature is able to be toggled and editing in either the Hud editor or Modules is super easy
## Multiplayer
